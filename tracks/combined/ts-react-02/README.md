# Typowany reducer i Context

## Kontekst

Złożony formularz ma jawne zdarzenia i stan, a konsumenci Context nie mogą działać poza Providerem.

## Decyzje

Unia rozłączna modeluje akcje, reducer jest czysty, a własny hook zgłasza kontrolowany błąd bez wartości domyślnej udającej stan.
