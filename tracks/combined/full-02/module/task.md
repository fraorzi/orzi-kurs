# Wejdź w obcy kod i bezpiecznie napraw incydent

Uzupełnij handler oraz notatkę decyzji. Reprodukcja: po błędzie event pozostaje oznaczony jako seen, retry jest ignorowany; każdy dokument powoduje osobny fetch, a log ujawnia sekret. Napraw kod, zachowaj kolejność dokumentów i opisz przyczynę, test regresji, metrykę rollout oraz warunek rollback.
