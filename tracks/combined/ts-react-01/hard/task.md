# Generyczny komponent danych

Zaimplementuj generyczny `DataTable<T>` z typowanymi kolumnami i stabilnym kluczem. Pusta kolekcja ma mieć podpis dostępny dla czytnika ekranu.

Zachowaj kontrakt między warstwami, dopisz test regresji i uzasadnij najważniejszą decyzję przed próbą rozszerzania zakresu.
