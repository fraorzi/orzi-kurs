# Generyczny komponent danych

## Kontekst

Biblioteka UI ma renderować różne rekordy bez `any`, utraty inferencji i kluczy opartych na indeksie.

## Decyzje

Generyczne propsy wiążą typ wiersza, kolumn i stabilnego `keyOf`; semantyczna tabela zachowuje nagłówki.
