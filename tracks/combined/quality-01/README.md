# Regresja, a11y i wydajność zastanego feature

## Kontekst

Lista ma błąd po reorderze, niedostępne przyciski i kwadratową selekcję. Zmiana musi mieć test regresji i zachować zachowanie użytkownika.

## Decyzje

Stabilne ID naprawia regresję, jawna etykieta poprawia a11y, a indeks Map usuwa powtarzane liniowe wyszukiwanie.
