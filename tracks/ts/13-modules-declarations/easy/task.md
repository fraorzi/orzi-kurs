# Easy — publiczne API modułu cen

Zadanie jest wieloplikowe. Uzupełnij implementację i `src/index.ts`.

Publiczne API ma wystawiać:

- wartość `formatMoney`,
- wartość `DEFAULT_CURRENCY`,
- typy `Currency` i `Money`.

Nie eksportuj wewnętrznej funkcji `minorUnits`. Przy włączonym
`verbatimModuleSyntax` typy muszą używać `export type`.
