# Easy — typy wyprowadzone z rejestru tras

Uzupełnij typy i funkcje na podstawie `ROUTES`. Nie przepisuj ręcznie unii nazw ani
ścieżek.

- `RouteName` — klucze rejestru,
- `RoutePath` — unia wszystkich ścieżek,
- `pathFor(name)` — ścieżka właściwa dla podanej nazwy,
- `isRouteName(value)` — predykat sprawdzający istnienie klucza.

Dodanie nowej trasy do obiektu ma automatycznie aktualizować wszystkie typy.
