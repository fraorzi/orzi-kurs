# JDK 25: stabilne API i preview

## Grupa

UTP / aktualizacja narzędziowa

## Kiedy

Gdy projekt migruje z poprzedniego LTS i trzeba oddzielić stabilne elementy Java 25
od preview wymagającego `--enable-preview` oraz świadomej polityki aktualizacji.

## Pułapki

„Dostępne w JDK 25” nie znaczy „stabilne”. Preview może zmienić API lub zniknąć,
a kod skompilowany z preview wymaga zgodnego uruchomienia.
