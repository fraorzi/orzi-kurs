# Tablice i macierze nieregularne

## Grupa

PPJ

## Kiedy

Gdy algorytm ma bez mutacji obracać macierz i bezpiecznie agregować wiersze o różnej długości.

## Pułapki

`array.clone()` kopiuje płytko, a założenie prostokątnej macierzy kończy się błędem dla jagged arrays.
