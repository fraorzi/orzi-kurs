# Abstrakcje, generyki i kolekcje modelu

## Grupa

GUI

## Kiedy

Gdy UI zależy od interfejsu repozytorium, a model wybiera List/Set/Map według semantyki.

## Pułapki

Klasa anonimowa i lambda nie zastępują dobrej granicy; generyk bez ograniczeń może dopuścić zły typ.
