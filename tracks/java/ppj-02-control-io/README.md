# Sterowanie, argumenty i format wyniku

## Grupa

PPJ

## Kiedy

Gdy program konsolowy interpretuje argumenty, używa switch expression i zwraca stabilny komunikat.

## Pułapki

Nie ufaj długości `args`; `Scanner` i formatowanie zależne od locale mogą dać nieprzenośny wynik.
