# Hints

## Hint 1

Dobierz granice generyków, kolekcję lub executor do kierunku przepływu danych.

## Hint 2

Każdy AutoCloseable/executor/transakcja potrzebuje jawnego cleanupu także po wyjątku.

## Hint 3

Nie ukrywaj błędu szerokim catch; dodaj test race, retry, malformed input lub partial failure.
