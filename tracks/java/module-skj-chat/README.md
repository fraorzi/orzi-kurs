# Moduł SKJ: protokół czatu

## Grupa

SKJ

## Kiedy

Gdy wieloklientowy czat wymaga wersjonowanego framingu, walidacji nicku i kontrolowanego rozłączenia.

## Pułapki

Broadcast nie może blokować wszystkich na jednym wolnym kliencie; tekst musi mieć limit bajtów i jawne UTF-8.
