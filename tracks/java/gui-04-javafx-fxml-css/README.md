# JavaFX: FXML, kontrolery i CSS

## Grupa

GUI

## Kiedy

Gdy widok FXML ma kontroler, stabilne `fx:id`, zasoby i klasy CSS, ale logika pozostaje poza plikiem widoku.

## Pułapki

Loader musi mieć właściwy resource i controller; dynamiczne style inline utrudniają theme, a ID nie jest klasą CSS.
