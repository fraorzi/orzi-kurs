# Sortowanie, Comparator i wyszukiwanie

## Grupa

PPJ

## Kiedy

Gdy wynik ma stabilny wielopolowy porządek, a binary search działa na danych posortowanych tym samym komparatorem.

## Pułapki

Comparator niespójny z wyszukiwaniem zwraca przypadkowy indeks; odejmowanie liczb w comparatorze może się przepełnić.
