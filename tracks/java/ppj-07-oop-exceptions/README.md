# OOP, polimorfizm i własne wyjątki

## Grupa

PPJ

## Kiedy

Gdy model domenowy ma enkapsulować niezmienniki, używać polimorfizmu i odróżniać błąd walidacji.

## Pułapki

Publiczne mutowalne pola łamią enkapsulację; łapanie `Exception` ukrywa błędy programistyczne.
