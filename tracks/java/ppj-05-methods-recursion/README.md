# Metody, varargs i rekurencja

## Grupa

PPJ

## Kiedy

Gdy API agreguje argumenty i ma wariant rekurencyjny z jawnym warunkiem bazowym.

## Pułapki

Java przekazuje wartość referencji, nie obiekt przez referencję; rekurencja bez malejącego problemu przepełni stos.
