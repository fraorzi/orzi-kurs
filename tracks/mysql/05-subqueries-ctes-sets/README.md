# Podzapytania, CTE i zbiory

## Kiedy

Gdy wyrażasz istnienie relacji, dzielisz wieloetapowy raport na nazwane etapy albo przechodzisz po hierarchii bez logiki aplikacyjnej.

## Pułapki

JOIN do testu istnienia może zwielokrotnić rekordy; CTE nie gwarantuje materializacji; UNION usuwa duplikaty, UNION ALL je zachowuje.
