# Typy danych, czas, tekst i JSON

## Kiedy

Gdy projektujesz granicę danych tak, aby pieniądze nie traciły precyzji, zakresy czasu były jednoznaczne, a tekst i dokumenty JSON miały świadomy kontrakt.

## Pułapki

FLOAT nie nadaje się do pieniędzy; `BETWEEN` utrudnia granice okresów; collation steruje równością; JSON nie zastępuje relacyjnych constraints.
