# Views, generated columns i triggery

## Kiedy

Gdy logika jest stabilnym kontraktem danych, potrzebujesz indeksowalnego wyrażenia albo audytu niezależnego od klienta.

## Pułapki

DEFINER może eskalować uprawnienia; trigger ukrywa koszt i kolejność efektów; generated column nie zastępuje modelu domenowego.
