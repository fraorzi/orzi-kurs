# Czysty cennik

Zaimplementuj `ProductTable`.

- Posortuj produkty rosnąco po cenie.
- Wyrenderuj listę w sekcji o nazwie dostępnej `Cennik`.
- Każda pozycja ma tekst `<name>: <price z dwoma miejscami> zł`.
- Pokaż `Razem: <suma z dwoma miejscami> zł`.
- Nie mutuj tablicy ani produktów otrzymanych w propsach.
- Ten sam props ma dawać ten sam wynik przy kolejnym renderze.
