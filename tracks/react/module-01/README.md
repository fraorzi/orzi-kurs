# Moduł 01 — lokalna tablica zadań zespołu

Pierwszy moduł React łączy fundamenty bez sieci i bez zewnętrznego store:

- wieloplikowy podział odpowiedzialności,
- reducer z akcjami domenowymi,
- osobne contexty stanu i dispatchu,
- kontrolowany, dostępny formularz,
- dane pochodne przez selektory,
- niemutowalne aktualizacje kolekcji,
- testy zachowania użytkownika.

To mały przekrój typowego feature’u produktowego, a nie demonstracja pojedynczego
hooka.
