# Tablica wyników

Zaimplementuj `ScoreBoard`.

Komponent zaczyna od wyniku `0:0`. Renderuje dwa elementy `output` o nazwach
`Gospodarze` i `Goście` oraz przyciski `Punkt dla gospodarzy` i
`Punkt dla gości`.

Każde kliknięcie zwiększa tylko odpowiednią część obiektu stanu. Nie mutuj
istniejącego obiektu i nie zgub drugiego pola podczas tworzenia następnej wartości.
