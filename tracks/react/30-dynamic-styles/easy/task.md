# Zbuduj semantyczny pasek postępu

Uzupełnij `ProgressBar` tak, aby szerokość `.progress-bar__fill` odpowiadała
procentowi `value / max` i była ograniczona do zakresu 0–100%. Zachowaj statyczne
klasy i semantykę `progressbar` wraz z wartościami ARIA.

Dynamiczną szerokość przekaż przez obiekt `style`. Nie przenoś stałych reguł
wyglądu do JSX.
