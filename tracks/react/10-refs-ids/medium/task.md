# Osobne ID dla każdej instancji pola

Tryb: uzupełnienie. W `starter.tsx` jest punkt wyjścia. Dopisz brakujące zachowanie opisane poniżej.

Popraw `ApiKeyField`. Komponent dostaje tekst etykiety `label` i wskazówki `hint`.
Wyświetl etykietę, input i tekst wskazówki.
Połącz etykietę z inputem przez `htmlFor` i `id`. Wygeneruj ID przez `useId`,
żeby dwa pola na tej samej stronie nie miały tego samego identyfikatora.
Kliknięcie etykiety ma wskazywać input należący do tej instancji.
