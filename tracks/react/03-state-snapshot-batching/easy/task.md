# Przełączanie szczegółów

Zaimplementuj `ToggleDetails`.

Początkowo szczegóły mają być ukryte, a przycisk ma mieć nazwę
`Pokaż szczegóły`. Kliknięcie pokazuje akapit z przekazaną treścią i zmienia nazwę
przycisku na `Ukryj szczegóły`. Kolejne kliknięcie ponownie ukrywa akapit.

Użyj jednego booleanowego stanu. Nie chowaj treści wyłącznie przez CSS.
