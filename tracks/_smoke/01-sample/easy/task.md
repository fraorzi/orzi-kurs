# Suma liczb parzystych

Napisz funkcję `sumEvens(nums)`, która zwraca sumę parzystych liczb z tablicy `nums`.
Funkcja **nie może** mutować tablicy wejściowej.

## Sygnatura

```js
export function sumEvens(nums) { /* ... */ }
```

## Przykłady

| wejście            | wynik |
| ------------------ | ----- |
| `[1, 2, 3, 4]`     | `6`   |
| `[1, 3, 5]`        | `0`   |
| `[]`               | `0`   |
| `[-2, -1, 0, 5]`   | `-2`  |
