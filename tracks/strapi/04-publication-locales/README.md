# Draft & Publish oraz i18n

## Kiedy

Gdy frontend preview i publiczny API potrzebują różnych wersji treści, a redakcja utrzymuje niezależne lokalizacje jednego dokumentu.

## Pułapki

Publikacja jednej lokalizacji nie publikuje automatycznie wszystkich. Publiczny endpoint bez jawnego `published` może ujawnić draft.
