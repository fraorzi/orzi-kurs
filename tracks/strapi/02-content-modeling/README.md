# Relacje, komponenty i dynamic zones

## Kiedy

Gdy projektujesz treść wielokrotnego użycia, relacje domenowe i elastyczne sekcje strony bez wciskania całego modelu w JSON.

## Pułapki

Dynamic zone bez dyskryminatora jest trudna do walidacji. Relacja many-to-many bez właściciela i limity populate prowadzą do kosztownych zapytań.
