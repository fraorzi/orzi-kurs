# Struktura projektu Strapi 5 i typy generowane

Strapi 5 identyfikuje każdy content type przez **UID** — łańcuch
`<namespace>::<collection>.<contentType>` w trzech przestrzeniach:
`api` (własne content types), `plugin` (np. `users-permissions`) i `admin`
(wewnętrzne typy panelu). Tylko przestrzeń `api` jest bezpieczna do
rozszerzania własnym kodem — pluginowe i adminowe UID-y są cudzym
kontraktem i nie wolno ich traktować jak zwykłego zasobu ani jak ścieżki
URL.

`strapi ts:generate-types` generuje `types/generated/contentTypes.d.ts` na
podstawie `schema.json` każdego content type. Deklaracje są **wyprowadzone**,
nie źródłowe: edycja pliku ręcznie znika przy następnym uruchomieniu, a sam
schemat i wygenerowane typy potrafią się rozjechać — ktoś doda pole w panelu
i zapomni odpalić generator, albo skomituje typy bez schematu, który je
wyprodukował.

## Kiedy używać

- Parsowanie i budowanie UID content type we własnym kodzie: rejestr
  serwisów, walidacja konfiguracji pluginu, routing wewnętrzny.
- Wyprowadzanie publicznego kontraktu pól z atrybutów schematu — np. do
  dokumentacji API albo osobnej warstwy serializacji.
- Sprawdzanie zgodności `schema.json` z wygenerowanymi typami w CI, żeby
  wyłapać rozjazd przed deployem, a nie na produkcji.

## Kiedy unikać

- Nie parsuj UID przez proste `split(".")` bez walidacji przestrzeni nazw —
  `plugin::` i `admin::` mają inną semantykę i inne gwarancje niż `api::`.
- Nie commituj wygenerowanych typów bez schematu, który je wyprodukował —
  trzymaj oba w tym samym PR, inaczej review nie wyłapie rozjazdu.
- Nie zgaduj kardynalności ani nazw pól z typów `any` — brak `strict` w
  `tsconfig` maskuje rozjazd zamiast go wyłapać w kompilacji.

## Pułapki

- UID content type nie jest ścieżką URL — REST endpoint dla
  `api::article.article` to `/api/articles`, nie `/api/api::article.article`.
- Ręczna edycja `types/generated/**` znika przy kolejnym
  `ts:generate-types`; traktuj katalog jak build output.
- Pole `private: true` i typ `password` to dwa różne mechanizmy ukrywania
  danych — publiczny kontrakt pól musi wykluczyć oba osobno.
- Rozjazd schema/generated bywa cichy: kod kompiluje się na starych typach
  aż do dnia, gdy ktoś doda pole i nie zregeneruje deklaracji.
