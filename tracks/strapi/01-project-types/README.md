# Projekt Strapi 5 i typy generowane

## Kiedy

Gdy orientujesz się w `src/api`, schematach content types, konfiguracji i generowanych deklaracjach TypeScript przed zmianą backendu.

## Pułapki

Nie edytuj plików `types/generated` ręcznie i nie traktuj UID content type jako ścieżki URL. Po zmianie schematu typy mogą być nieaktualne.
