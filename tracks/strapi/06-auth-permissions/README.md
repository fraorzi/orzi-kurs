# Uwierzytelnianie, tokeny i permissions

## Kiedy

Gdy chronisz Content API przez JWT użytkownika albo API token i każdej roli przyznajesz tylko jawnie potrzebne akcje.

## Pułapki

Sam poprawny token nie daje prawa do zasobu. Public role jest domyślnie ograniczona, a sekrety i pełny JWT nie mogą trafiać do logów.
